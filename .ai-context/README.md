# Project Context

## Overview

Hangry Hippo is a Django/DRF backend and React frontend used for automated-testing coursework.

Current priority: maintain the backend delivery-cost rules and their pytest coverage.
Tests use pytest for backend units, Jest for frontend functional tests, and Cypress for acceptance tests.
